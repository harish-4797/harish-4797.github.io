# Nimmagadda Harish — Portfolio

Personal portfolio of **Nimmagadda Harish**, a full-stack developer from Guntur, India, working across React, Node.js, MongoDB, AI pipelines and browser-based computer vision.

**Live site:** https://harish-4797.github.io

## What's inside

- Bento-style hero with an illustrated avatar and a voiced intro (ElevenLabs recording, with the avatar's mouth synced to the audio)
- Five projects with case studies: Interview Prep Kit, SuthraChat, AR Jewelry Try-On, SuthraReach and an AI Travel Planner
- Scroll-reactive background, stacking project cards, scroll-highlighted text and count-up stats
- Downloadable CV, contact details, LinkedIn and GitHub links
- Light and dark themes, responsive down to phone width, and reduced-motion support

## Tech

A single static `index.html` with hand-written HTML, CSS and vanilla JavaScript. There's no build step and no framework. Fonts come from Google Fonts.

## Files

| File | Purpose |
|---|---|
| `index.html` | The whole site |
| `intro-voice.mp3` | Voice track for the intro |
| `Nimmagadda_Harish_Resume.pdf` | CV served by the Download CV button |
| `og-image.png` | Preview image for link sharing |
| `.nojekyll` | Tells GitHub Pages to serve files as-is |

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
